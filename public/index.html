代理使用说明

本服务提供文件下载代理与 API 透传代理。

使用方法

把需要访问的完整地址接在本服务域名后面：

https://本服务域名/https://目标地址

例如：

https://本服务域名/https://github.com/user/repo/releases/download/v1.0/file.zip

协议头可省略，默认按 https 处理：

https://本服务域名/github.com/user/repo/raw/main/file.txt

支持范围

  • 请求方式：GET、POST
  • 查询参数原样透传
  • 请求头原样透传（部分必要字段除外）
  • 下载：自动多分片并发，边下边传
  • API：请求与响应双向透传
  • POST 请求体上限 4 MB

允许的域名

目前仅允许下列域名及其子域名。

微软系：

  • microsoft.com、azure.com、windows.net、live.com
  • office.com、office365.com、sharepoint.com、onedrive.com
  • msn.com、bing.com、visualstudio.com、vscode.dev
  • github.com、githubusercontent.com、githubassets.com、github.io
  • blob.core.windows.net

Google 系：

  • google.com、googleapis.com、gstatic.com、googlevideo.com
  • youtube.com、ytimg.com、ggpht.com、googleusercontent.com
  • gvt1.com、gvt2.com、gvt3.com
  • blogspot.com、blogger.com、android.com

限制

  • 禁止访问内网地址
  • POST 请求体超过 4 MB 将被拒绝
  • 大文件上传请先上传到网盘或对象存储，再提供链接
  • 单次请求最长执行时间约 280 秒

错误响应

所有错误以纯文本返回，两行：第一行中文，第二行英文。

请求体过大，超过 4 MB 限制，请先上传成文件再提供链接
Payload too large, exceeds 4 MB limit. Please upload the file first and provide a link.

示例

下载文件：

curl -O https://本服务域名/https://github.com/user/repo/releases/download/v1.0/file.zip

调用 API：

curl -X POST https://本服务域名/https://api.github.com/repos/user/repo/issues \
  -H "Content-Type: application/json" \
  -d '{"title":"hello"}'

本服务仅供个人使用。
