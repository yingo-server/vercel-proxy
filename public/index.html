HTTP Proxy

Endpoint

  GET  /{URL}
  POST /{URL}

Examples

  浏览器访问
    https://{host}/https://example.com/page.html

  跳过域名白名单
    https://{host}/https://example.com/page.html?white=Y

  curl
    curl https://{host}/https://example.com/data.json

  POST
    curl -X POST -d @body.json https://{host}/https://api.example.com/endpoint

Behavior

  - 仅代理 http/https 协议
  - 拒绝内网地址与保留地址
  - 默认启用域名白名单
  - 参数 white=Y 跳过域名白名单
  - 内网地址在任何情况下均被拒绝
  - HTML 响应会重写 src、href、action、srcset、style、内联脚本
  - 支持多分片 Range 下载

Limits

  - 请求体上限 4 MB
  - HTML 重写体积上限 8 MB
  - 响应受平台函数超时限制
